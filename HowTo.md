## Prompting Strategy

### Modular Skill Decomposition

We decomposed the paper summarization task into **three specialized skills**,
each with a detailed prompt specifying exact input/output formats and quality
criteria. Skills chain together: each produces structured intermediate output
that feeds into the next skill.

### Skill 1: Paper Understanding (`skills/paper_understanding.md`)

The prompt instructs the agent to:
- Read ALL 47 pages (not skip appendix/references)
- Extract into 7 categories: identity, problem, hypotheses, methodology,
  experiments, results, limitations
- Produce strict JSON output with typed fields
- Answer 6 analytical questions about the paper
- **Identify unstated limitations** — not just acknowledged ones
- Quality criterion: "Every number must be cited with page/section"

### Skill 2: Figure Generation (`skills/figure_generation.py`)

Implemented as Python (deterministic layout logic). Generates 6 publication-quality
figures:
- **Fig 1:** System architecture pipeline (5 phases, color-coded)
- **Fig 2:** Data flow diagram (sources → processing → analysis → outputs)
- **Fig 3:** Three-method analysis detail (4 panels: Spearman, RF, Transformer, Validation)
- **Fig 4:** RAG query pipeline (5 stages + FAISS + Dictionary integration)
- **Fig 5:** Results comparison (4 panels: category R², spatial CV gap, variance
  decomposition, linear vs nonlinear)
- **Fig 6:** LSI evaluation (horizontal bar chart with error bars)

Style: Nature/AAAS-inspired color palette, consistent typography, 250 DPI,
white backgrounds.

### Skill 3: Summary Writing (`skills/summary_writing.md`)

The prompt specifies:
- 6 required sections with content requirements
- Writing principles: accuracy (traceable claims), clarity, structure,
  completeness, visual enhancement
- Quality checklist (8 items): ≥4 figures, data table complete, ≥3 unstated
  limitations, methodology detailed for reproduction, self-contained
- **CRITICAL:** No placeholder text — every section fully written

### Orchestration: `skills/run_workflow.py`

Chains skills with explicit data flow:
```
paper_text.txt → Skill 1 → paper_analysis.json → Skill 2 → figures/ → Skill 3 → paper_summary.md
```

## Interaction Flow

### Typical Workflow

```bash
# One command runs the entire agentic pipeline:
python skills/run_workflow.py
```

```
User provides: Academic paper (PDF or text file)
       ↓
[Skill 1: Paper Understanding Agent]
  Reads 47-page paper → structured JSON (4 RQs, 3 methods, 12 data sources,
  6 experiments, 12 limitations including 6 unstated)
       ↓
[Skill 2: Figure Generation Agent]
  Reads JSON → generates 6 publication-quality PNGs (250 DPI)
       ↓
[Skill 3: Summary Writing Agent]
  Reads JSON + figures → writes ~2500-word Markdown summary
       ↓
User receives: paper_summary.md (ready to read or convert to PDF)
```

### Customization for Other Papers

1. Place paper text in `data/paper_text.txt`
2. Run: `python skills/run_workflow.py`
3. Output in `results/paper_summary.md`

The skills are **paper-agnostic** — no paper-specific hardcoding.
