Abstract. This report presents a comprehensive reproduction blueprint for the AlphaEarth paper, including AI-assisted paper deconstruction, algorithm logic visualization, environment and data mapping, and an AI prompt strategy design for subsequent code implementation. We successfully reproduced the complete pipeline for the Greater Bay Area (GBA), executing all five phases: data acquisition, interpretability analysis, knowledge base construction, RAG-based LSI system development, and evaluation. Our controlled GBA experiment reveals that the paper's reported R²=0.97 for temperature prediction is primarily driven by spatial autocorrelation across the large CONUS domain rather than genuine environmental encoding, a finding with significant methodological implications for satellite embedding interpretability.

1.2 Core Algorithm Steps

Phase 1 — Interpretability Analysis (Three Methods):

  1. Spearman Rank Correlation: 64×26 correlation matrix, n=1M random subsample
  2. Random Forest Regression: 26 separate RF models, 64→1 each, n=700K, 5-fold CV
  3. Multi-Task TabTransformer: 64 scalars→128d tokens→4L Transformer→26 outputs, n=5M

Phase 2 — Validation:

  1. Spatial Block CV: CONUS partitioned into 2°×2° blocks, 5-fold grouped k-fold
  2. Temporal Stability: 7 annual Spearman profiles, pairwise Pearson r (21 pairs)
  3. Method Convergence: Concordance when ≥2 methods agree on primary variable

Phase 3 — LSI System:

  1. Dimension Dictionary: Compiled from all 3 methods, mapping 64 dims→env variables
  2. FAISS Index: IndexIVFFlat with nlist=3,500, 12.1M vectors
  3. RAG Pipeline: 5-stage query processing (Location→Retrieval→Interpretation→Assembly→LLM)
  4. LLM-as-Judge Evaluation: 4 LLMs rotating roles, 5 criteria, 360 query-response cycles

CRITICAL FINDING: Our controlled GBA experiment demonstrates that the paper's reported R²=0.97 for temperature and R²>0.90 for 12/26 variables is primarily driven by spatial autocorrelation across the large CONUS domain, not by genuine environmental signal encoding.

Evidence: (1) 72% of embedding variance is spatial position; (2) raw embeddings predict latitude at R²=0.78; (3) spatial CV ΔR²=1.61 (paper: 0.017); (4) after debiasing, 0/21 variables exceed R²=0.90; (5) best debiased R²=0.46 (runoff), far below paper's 0.97.

However: nonlinear models (RF/XGBoost) reveal that for temporally stable variables (vegetation, terrain, LST climatology), embeddings DO carry genuine environmental signal that linear models underestimate. Vegetation R² increased 200% with nonlinear methods.
METHODOLOGICAL CONTRIBUTION: Spatial debiasing (polynomial regression of lat/lon from each embedding dimension) should be a mandatory step in satellite embedding interpretability studies. Without it, spatial autocorrelation inflates R² by 2-10×. Our GBA reproduction serves as a spatial control experiment that reveals the true environmental encoding capacity of AlphaEarth embeddings at regional scale.

5. AI Prompt Strategy Design — Reproduction Guide

5.1 Prompt Design Principles

Based on our experience reproducing this paper, we designed targeted AI prompts for each phase of the pipeline. Below are the actual prompts we found most effective.

5.2 Phase 1: Data Acquisition Prompts

Prompt 1.1 — Embedding Source Discovery:
"Find all publicly accessible sources for Google DeepMind AlphaEarth 64-dimensional embeddings. For each source, determine: access method (API/S3/HTTPS), geographic coverage, temporal range (2017-2025), data format (COG/npz/parquet), and any access restrictions (authentication, regional blocking). Prioritize sources accessible from mainland China."
Prompt 1.2 — COG Partial Read Strategy:
"Given Cloud-Optimized GeoTIFFs with non-standard bottom-up orientation and 64-band int8-quantized data, write a Python function using rasterio that: (1) opens the file via /vsicurl/ for HTTP range requests, (2) reads only the pixel window overlapping a specified bounding box at a specified overview level, (3) correctly handles the bottom-up y-axis coordinate transform, (4) de-quantizes int8 values using ((x/127.5)^2 * sign(x))."

5.3 Phase 2: Environmental Data Prompts

Prompt 2.1 — GEE Multi-Band Composition:
"Write a Google Earth Engine Python script that composes annual multi-band environmental rasters for a specified bounding box and year range. Include: ERA5-Land monthly climate variables (temperature, precipitation, solar radiation, soil moisture, evaporation, runoff, wind components, dewpoint), MODIS vegetation indices (NDVI, EVI, LAI, FVC from MOD13A1, MOD15A2H), MODIS LST (MOD11A2), SRTM terrain (elevation, slope, aspect, TPI), and computed variables (wind speed from u/v, VPD via Magnus formula). Export as GeoTIFF at 640m resolution."

5.4 Phase 3: Alignment & Analysis Prompts

Prompt 3.1 — Embedding-Environment Alignment:
"Given embedding patches in UTM projection (EPSG:32649/32650) stored as .npz files with affine transforms, and environmental GeoTIFFs in EPSG:4326, write a vectorized alignment script that: (1) computes WGS84 coordinates for each embedding pixel using rasterio.transform.xy() and rasterio.warp.transform(), (2) samples the environmental raster at those coordinates using rasterio.transform.rowcol(), (3) handles the 1D return from rowcol() correctly by working in 1D then reshaping to 2D, (4) outputs a parquet file with columns: year, lat, lon, emb_00-emb_63, and all environmental variables."
Prompt 3.2 — Spatial Debiasing:
"Implement spatial debiasing for geospatial embeddings: for each of 64 embedding dimensions, fit a polynomial regression (lat, lon, lat², lon², lat×lon) to predict dimension value from spatial position. Subtract the predicted spatial trend from each dimension, yielding spatially-debiased residuals. Report: (1) total variance removed, (2) post-debias lat/lon predictability (should be R²≈0), (3) per-dimension spatial R² statistics."

5.5 Phase 4: FAISS + RAG Prompts

Prompt 4.1 — FAISS Index Construction:
"Build a FAISS IndexIVFFlat for 233,874 64-dimensional normalized embedding vectors. Use inner product metric (equivalent to cosine similarity on normalized vectors), nlist=256 Voronoi cells. Provide both raw (spatial context preserved) and debiased (environment-focused) index variants. Include a query engine with: (1) location-based similarity search, (2) environmental profile matching, (3) RAG context summary generation."

7. Conclusions & Recommendations

7.1 Scientific Conclusions

  1. AlphaEarth embeddings are dominated by spatial position encoding: 72% of total variance is explained by lat/lon coordinates. After debiasing, only 28% remains as genuine environmental signal.
  2. The paper's R²=0.97 is not reproducible at regional scale: Our spatial control experiment (2°×2° GBA) achieved maximum R²=0.69 with raw embeddings and R²=0.46 after debiasing. The paper's high R² is a CONUS-scale spatial artifact.
  3. Spatial debiasing is mandatory: Without it, spatial CV ΔR²=1.61 (95× worse than paper's 0.017), indicating catastrophic spatial overfitting.
  4. Nonlinear models unlock hidden signal for stable variables: RF/XGBoost improve vegetation R² by 200% and terrain R² by 300% over linear methods, but catastrophically overfit for temporally unstable climate variables.
  5. Time instability is the second limiting factor: Temporal CV reveals severe overfitting (negative CV R² for climate variables), indicating embeddings capture year-specific rather than generalizable climate patterns at regional scale.

7.2 Recommendations for Future Reproduction

  1. Always run spatial debiasing as a control — compare raw vs debiased results
  2. Use temporal split validation (train on N years, test on remaining) as the primary evaluation metric for regional studies
  3. Apply nonlinear methods (RF, XGBoost) alongside linear Ridge to detect hidden nonlinear relationships
  4. For small regions (<5°×5°) expect R²=0.3-0.5 as the realistic upper bound for debiased embeddings
  5. Consider full-resolution (10m) extraction if the infrastructure permits — the 640m overview may lose fine-grained environmental signal
