Abstract. This report presents a complete baseline reproduction of the AlphaEarth paper at the Greater Bay Area (GBA) scale, implemented entirely through AI-assisted coding (DeepSeek-V4-Pro via Claude Code). We reproduce the core interpretability pipeline (Spearman correlation, Random Forest regression, Ridge regression, XGBoost) on 234K embedding samples across 21 environmental variables. Our controlled spatial experiment reveals that the paper's reported R²=0.97 for temperature prediction is primarily driven by spatial autocorrelation across the CONUS domain rather than genuine environmental encoding. After spatial debiasing, 0/21 variables exceed R²=0.90, and 72% of total embedding variance is explained by spatial position alone. This finding has significant methodological implications for satellite embedding interpretability studies. The entire pipeline, from data loading to figure generation, is released as open-source code with comprehensive AI-assisted coding/debugging documentation.

1. Introduction

1.1 Target Paper

The AlphaEarth paper by Rahman (2026) investigates whether Google DeepMind's 64-dimensional satellite embeddings encode physically interpretable environmental features. The paper reports:

  • 12/26 environmental variables achieved R² > 0.90 when predicted from embeddings
  • Temperature and elevation approached R² ≈ 0.97
  • Spatial block cross-validation showed minimal overfitting (ΔR² = 0.017)
  • Temporal stability was near-perfect across 7 years (r = 0.963)
  • A Land Surface Intelligence (LSI) system using FAISS + RAG achieved LLM-as-Judge score of 3.74/5

2.2 Data Acquisition & Preprocessing

Embedding Source: Source Cooperative (AWS S3 mirror) — Cloud-Optimized GeoTIFFs with 64-band int8-quantized data, accessed via HTTPS /vsicurl/ for partial reads.

Environmental Data: Google Earth Engine (MODIS, PRISM, ERA5-Land, SRTM) — 21 variables across 5 categories (Climate, Vegetation, Hydrology, Temperature, Terrain).

  • De-quantization: float32 = ((int8/127.5)² × sign(int8))
  • Grid alignment: 640m resolution (overview level 5), 105 embedding tiles
  • Spatial debiasing: Polynomial regression (lat, lon, lat², lon², lat×lon) per dimension

    6. Methodology Recommendations

    Based on our reproduction experience, we recommend the following for satellite embedding interpretability studies:

    1. Always run spatial debiasing as a control. Compare raw vs debiased results. If the debiased R² drops by >50%, spatial autocorrelation is the dominant signal.
    2. Use multi-scale spatial CV. Test block sizes from 0.5° to 5°. If ΔR² increases as block size decreases, spatial overfitting is present.
    3. Include a lat/lon-only baseline. Before claiming embeddings encode environmental variables, show that lat/lon alone doesn't achieve similar R².
    4. Apply nonlinear methods. RF and XGBoost can reveal hidden signal that linear methods miss, especially for stable variables like vegetation and terrain.
    5. Use temporal split validation. Train on N years, test on different years. This is the strictest test of generalizability.
    6. Report per-category results. Aggregate metrics hide important heterogeneity — climate variables behave very differently from vegetation.

    7.2 Challenges & Resolutions

    See AI_CODING_LOG.md in the repository for a detailed log of all 7 errors and their AI-assisted resolution. Key lessons:

    • Windows GBK encoding is a persistent issue for scientific Python on Chinese Windows — use sys.stdout.reconfigure(encoding='utf-8') and avoid Unicode in print statements
    • FAISS wheel compatibility lags behind Python releases — make FAISS optional with graceful degradation
    • NumPy Generator API migration (randint → integers) is a common source of bugs — AI tools catch these quickly
    • Permutation importance memory scales with n_samples × n_trees — subsample to 10K for importance computation

    8. Conclusion

    This reproduction demonstrates that while AlphaEarth embeddings do encode physically meaningful environmental information, the paper's headline R² values are substantially inflated by spatial autocorrelation at the continental scale. At regional (GBA) scale, after proper spatial debiasing:

    • No variable achieves R² > 0.90 (paper: 12/26)
    • Best debiased R² = 0.46 for runoff (paper: 0.97 for temperature)
    • 72% of embedding variance is spatial position, 28% is environmental signal
    • Spatial CV overfitting is 12× worse than reported
    • Nonlinear methods improve stable variables (+200% vegetation) but overfit climate variables

    These findings do not invalidate the paper's core contribution — that AlphaEarth embeddings are physically interpretable — but they do demonstrate that spatial debiasing is a mandatory prerequisite for any claim about the environmental information content of satellite embeddings. The paper's methodology is sound in principle; our reproduction adds the critical spatial control experiment that was missing from the original analysis.
